# Welcome to leoyim-doc-template

This is a **static doc site** powered by Docusaurus.

## Getting Started

- Browse pages using the sidebar
- Click **`</> Source`** at the bottom of any page to view its raw Markdown source
- Add new `.md` or `.mdx` files to the `docs/` directory

## Template Documents

New to Markdown or this doc site? Check out the template references:

- [📄 English Template](template) — complete syntax reference
- [📄 中文模板](template-zh) — 完整语法参考

## Features

- Markdown & MDX — write content with rich formatting and JSX components
- View Source — every page has a button to show the original Markdown
- Full-text search — instant search across all pages
- Light/dark mode — built-in theme toggle
- Responsive — works on all screen sizes
- Static site — pre-rendered HTML, fast to load, easy to deploy
